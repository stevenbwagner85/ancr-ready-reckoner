Analytical Confidence Rating (AnCR) ready reckoner

A structured aid for judging how much confidence an intelligence assessment deserves. It turns the analyst’s answers to a set of prompt questions into the ingredients of an AnCR statement, one key judgement at a time.

Every rating is the analyst’s own judgement. Nothing is averaged, tallied or calculated: the tool makes the reasoning visible and keeps a record of it.

Offline HTML tool

One file. Save it to a local or shared drive and open it in any modern browser. It needs no installation and no internet connection, and it saves its results as an Excel workbook.

Excel template

The same assessment as a plain workbook. Each rating is chosen from a list. It contains no macros and no ActiveX controls, so there is nothing to enable or trust.

How it works

  • Each key judgement is scored against nine factors under three criteria: source base, analysis, and the complexity and volatility of the subject.
  • Each factor is rated Low, Moderate or High. There is no numeric scale: the analyst has to decide where it stands, with a statement describing what Low and High look like and room for notes.
  • The analyst then rates each criterion as a whole, and the judgement as a whole, in the same way.
  • The tool gathers the ratings, the factors rated High and Low and a writing frame, ready for the analyst to write the AnCR statement.

The two versions work together

A workbook saved from the HTML tool has the same layout as the Excel template. It can be edited in Excel and then opened again in the HTML tool.

The HTML tool sends nothing over the network. It keeps work in progress in the browser on that computer until you choose “Start again”.
